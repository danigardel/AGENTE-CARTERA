# Radar bursátil diario

Genera `dashboard.html` con noticias del día, una señal de sentimiento para cada empresa y datos de cotización, ratios PEG y PER, consenso de analistas y precio objetivo de Yahoo Finance cuando están disponibles. Incluye además la cartera configurada en `PORTFOLIO`, con cierres históricos, rendimientos por periodo y rendimiento máximo seleccionables. La cotización y las noticias no requieren claves; el análisis IA es opcional y necesita una clave Gemini.

El reporte también solicita un análisis estructurado a Gemini 3.8 Flash (`gemini-3.8-flash`) usando la API estándar `generateContent` (no Batch), con `gemini-3.7-flash` como alternativa si el servicio indica que el modelo no existe o ya no está disponible. Envía a Google las posiciones de `PORTFOLIO`, los datos de `COMPANIES`, titulares/resúmenes de los RSS de Yahoo Finance y un radar global con hasta 180 titulares recientes de Yahoo Finance, CNBC y WSJ. El radar global conserva los titulares en inglés, incluye fuente/fecha/enlace y se inyecta en `global_market_radar` para que Gemini detecte oportunidades externas; no se usa Grounding ni la herramienta de Google Search. Si falla un feed, se omite individualmente; si no se obtiene ninguna noticia de hoy, el prompt pide un análisis técnico basado en los datos disponibles. La petición usa un presupuesto de razonamiento de 2048 tokens. No se envían claves de API dentro del prompt.
El análisis se guarda en `gemini_cache.json` con un timestamp UTC y se reutiliza hasta el siguiente hito horario de análisis. `GEMINI_API_KEY` admite varias claves separadas por comas. Cada intento inicia con la clave siguiente a la que resolvió el análisis anterior; si falla una clave (429, 503 u otro error), se prueba la siguiente y se guarda la posición para el siguiente intento. Si falla todo el pool, solo se conserva el aviso hasta el siguiente hito (`TARGET_HOURS`) cuando todas las respuestas indiquen explícitamente una cuota diaria. Para 503, límites por minuto/tokens o errores 429 sin detalle diario claro, la caché registra la rotación y permite un nuevo intento tras 5 minutos, alineado con el cron de Actions. Importante: las cuotas de Gemini se aplican por proyecto, no por clave API; rotar varias claves asociadas al mismo proyecto no suma cuota. Google puede responder 429 por RPM, TPM o RPD (solicitudes/minuto, tokens/minuto o solicitudes/día). El aviso de cuota recomienda comprobar en AI Studio el proyecto realmente asociado a cada clave y los límites del modelo. La caché negativa guarda únicamente la huella SHA-256 y el índice del conjunto ordenado de claves (nunca las claves); al cambiar el conjunto se reinicia la rotación. El archivo se excluye de Git. GitHub Actions restaura la caché persistente con `actions/cache/restore` y guarda una clave nueva por cada timestamp de intento; así se respeta que las entradas de Actions Cache sean inmutables.

## Ejecución local

Requiere Python 3.10 o posterior.

```powershell
python -m pip install -r requirements.txt
python daily_report.py
```

El archivo se crea en `dashboard.html`. Se puede elegir otra ruta:

```powershell
python daily_report.py --output public\index.html
```

La lista de seguimiento está en `COMPANIES` y la cartera fija en `PORTFOLIO`, ambas en `daily_report.py`. Están activas las 48 empresas e instrumentos de la lista original; Space Innovators ETF (`YODA.L`) continúa comentado porque Yahoo Finance no reconoce ese ticker. SpaceX no cotiza en bolsa y no dispone de ticker público. La cartera usa símbolos negociados en euros cuando están disponibles (EUNL.DE para iShares Core MSCI World, ASML.AS y XDWT.DE); los activos estadounidenses se convierten desde USD con el cambio histórico USD/EUR de cada fecha. Los periodos comparan el último cierre disponible en o antes de hoy menos 1, 7, 30, 180 y 365 días naturales. El rendimiento MAX usa las posiciones e inversiones base configuradas, sin depender de las fechas de compra.

## Automatización y GitHub Pages

El workflow `.github/workflows/daily_report.yml` genera y despliega el dashboard cada **5 minutos** (el intervalo mínimo de GitHub Actions para `schedule`). GitHub puede retrasar o descartar ejecuciones programadas cuando hay carga, así que no se garantiza una actualización exacta cada 5 minutos. Si una ejecución sigue en curso, no se cancela para iniciar otra; se procesa la más reciente cuando queda disponible. El cron se ejecuta en UTC, pero la hora que aparece en el informe usa `Europe/Madrid`. También se puede iniciar manualmente con `workflow_dispatch`. Cada tarjeta muestra el último precio que Yahoo Finance devuelve durante esa generación, convertido a euros cuando hay tipo de cambio disponible; el proveedor puede retrasar los datos o no cambiar el precio cuando el mercado está cerrado. Las ejecuciones programadas deben estar habilitadas y el workflow debe estar en la rama predeterminada del repositorio.

Para activar el análisis IA, crea una o varias claves Gemini en Google AI Studio y guárdalas en un único secreto de repositorio **Settings → Secrets and variables → Actions → New repository secret → `GEMINI_API_KEY`**, separadas por comas y sin espacios obligatorios (por ejemplo `clave1,clave2,clave3`). Localmente, configura `GEMINI_API_KEY` con el mismo formato antes de ejecutar el informe. Si falta una clave o Gemini no responde, el informe se genera igualmente y muestra un aviso en la sección de análisis. El modelo predeterminado es `gemini-3.8-flash`; puede cambiarse con `GEMINI_MODEL`, y cuando el modelo elegido devuelve un error de modelo inexistente se prueba `gemini-3.7-flash`. El presupuesto de razonamiento está fijado en 2048 tokens. `INVESTOR_PROFILE` permite personalizar el perfil; este valor se envía a Gemini, así que no incluyas información sensible. En GitHub Actions, los ajustes opcionales se leen de **Actions variables**. Con respuestas válidas, el análisis se renueva en los hitos de las 00:00, 09:00, 12:00, 15:00, 18:00 y 21:00 en `Europe/Madrid`, no en cada generación del dashboard. La clave inicial rota de una consulta a la siguiente, y los fallos prueban secuencialmente el resto del pool; solo cuando todas fallan se publica el aviso hasta el próximo hito. Los feeds macro RSS son públicos y no requieren claves; las peticiones a Gemini siguen sujetas a cuotas y posibles costes del proyecto.

En el repositorio, activa GitHub Pages con **GitHub Actions** como fuente de despliegue. El workflow necesita los permisos de Pages y OIDC que declara en el YAML. Tras una ejecución correcta, el dashboard se publica como `index.html`.

El dashboard incluye mapas de calor y líneas intradía del rendimiento medio de la lista de seguimiento y de la cartera. El mapa de cartera asigna a cada posición un área proporcional a su porcentaje del valor actual total. Una cotización solo se considera actualizada hoy si Yahoo Finance proporciona la fecha de mercado y esta coincide con la fecha local de su bolsa; cotizaciones antiguas o sin fecha/datos se ordenan debajo de una línea discontinua en la lista, y sus bloques de heatmap usan el color del fondo. Los nombres y rendimientos visibles en los mapas usan texto negro con contorno claro para mejorar el contraste. Los históricos intradía se descargan de Yahoo Finance en intervalos de 5 minutos al generar cada página; el cambio diario de cada bloque se calcula con los cierres previos de Yahoo. En móviles la tabla de cartera se presenta como tarjetas compactas; los datos de inversión base y valor actual solo aparecen en el periodo MAX. D3.js se carga desde CDN para generar los SVG; la página es un único HTML generado, aunque las gráficas requieren conexión para cargar D3.

## Fuentes y límites

- Google News RSS proporciona titulares del dashboard y Yahoo Finance RSS aporta titulares/resúmenes para el análisis por empresa; el radar macro agrega hasta 180 titulares de hoy de Yahoo Finance, CNBC y WSJ, sin traducirlos. En todos los casos solo se conservan los publicados en la fecha local del informe. Google Translate muestra sus traducciones al español en los titulares clave y en las tarjetas; si la traducción no está disponible, se conserva el titular original y se indica el aviso.
- VADER puntúa el tono del titular original. La señal alcista/neutral/bajista es una heurística de sentimiento, no una predicción ni asesoramiento.
- Yahoo Finance vía `yfinance` aporta precio actual, variación diaria, ratios PEG y PER (TTM), consenso, precio objetivo y sector cuando el proveedor los entrega. El PEG se muestra en verde (< 1,0), naranja (1,0–1,5) y rojo (> 1,5), y sin color si falta o es negativo; ambos ratios son referencias informativas, no recomendaciones de inversión. El precio mostrado es la cotización disponible al generar ese informe; los datos pueden faltar o tener retraso según el proveedor/mercado. Los errores y datos ausentes se indican en cada tarjeta.
- Gemini Flash recibe la cartera, las empresas de `COMPANIES` y el nodo `global_market_radar`; el contexto sectorial solo se incluye para empresas con sector devuelto por Yahoo Finance. La respuesta se valida y se descartan recomendaciones con tickers que no están en la lista de seguimiento o en la cartera correspondiente. El análisis puede equivocarse, no conoce el horizonte ni la tolerancia al riesgo del usuario y no es asesoramiento financiero personalizado.
- Se resume el consenso por empresa. La cartera propia es una lista estática definida por el usuario; no se consultan ni infieren las tenencias internas de fondos a partir de recomendaciones.
- El desplegable de la lista de seguimiento reordena las tarjetas en el navegador (rendimiento diario, PEG, consenso o sentimiento); las empresas sin dato van siempre al final.
- En la tabla de cartera, los selectores cambian entre rendimientos 1D, 1W, 1M, 6M y 1Y, o ganancia/rendimiento MAX. Activo, posición y precio actual permanecen visibles; inversión base y valor actual aparecen solo en MAX.
- La sección de análisis IA indica la fecha/hora local de su último resultado válido, que puede ser anterior a la actualización de cotizaciones por el periodo de caché de Gemini.
